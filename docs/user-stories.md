# User Stories

---

## Authentication

- Users can register a new account to save expenses
- users can log in account to view expenses
- Users can log out so unathorised users cannot use their account

---

## Expense Management

- Users can store expenses
- Users can view expenses
- Users can update their expenses
- Users can delete their expenses
- Users can tally budgets
- Users can view their monthly/yearly spending summary

---

## Categories

- Users can create categories
- Users can edit categories
- Users can delete categories
- Users can attach categories to expenses

---

## Filtering

- Users can filter expenses by month/year
- Users can filter expenses by category
- Users can search for expenses

---

## Summary

- Users can view their monthly/yearly spending summary
- Users can view their total spending by category

---

## Dashboard

- users can view an overview of their expenses
- users can view recent spendings

---
